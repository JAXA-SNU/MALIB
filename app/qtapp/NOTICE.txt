■ 本ソフトウェアについて

  RTKNAVI-Qt は MALIB (MADOCA-PPP Library) のリアルタイム測位 GUI、
  RTKPLOT-Qt は測位解の描画 GUI です。
  MALIB の Windows GUI (C++Builder/VCL 依存) を Qt へ移植し、Windows と
  Linux の双方で同一ソースからビルドできるようにしたものです。

  本バージョンには未実装・未検証の機能があります。導入前に確認してください。

    - 時刻スクロールバー、アニメーション

      (ダイアログ上でグレーアウトされ、理由がツールチップに出ます)

  【未検証】
    - 長時間運用およびファイルスワップ出力 (::S=)
    - Qt 未導入の他 PC への配布

  【検証済み】
    - 実機動作試験 (2026-07-31, Windows 11)
      u-blox / Septentrio / NovAtel のシリアル接続、NTRIP、MADOCA-PPP(L6)
    - Options 設定 174 項目の書き換え試験 (305 ケース / 失敗 0)
      Windows・Linux の両環境で実施
    - CUI 版 rtkrcv との測位結果照合 (3642 エポックで完全一致)
    - Windows 版と Linux 版の測位結果照合 (収束後の位置差 中央値 0.09 mm)

■ 起動方法

  bin/rtknavi_qt.exe (測位)、bin/rtkplot_qt.exe (描画) を実行してください。
  bin/rtknavi_cli.exe は設定点検用のコマンドライン版です
  (--selftest / --coverage)。GUI 版はシェルが終了を待たないため、
  出力のリダイレクトや終了コードの取得にはこちらを使用してください。
  DLL は実行ファイルと同じフォルダに配置されているため、環境変数 PATH の
  設定は不要です。フォルダ構成を保ったまま移動・コピーしてください。

  設定ファイルを指定して起動する場合:
    rtknavi_qt.exe -o <設定ファイル>
    rtknavi_qt.exe -o <設定ファイル> -s     (起動と同時に測位開始)

  RTKPLOT-Qt:
    rtkplot_qt.exe <解ファイル.pos>
    rtkplot_qt.exe -p tcpcli://localhost:8888   (起動と同時にリアルタイム接続)

  RTKNAVI-Qt の解を RTKPLOT-Qt でリアルタイム表示する場合は、RTKNAVI 側の
  出力を TCP Server に、RTKPLOT 側の接続を TCP Client にしてください。
  両方を TCP Client にすると待ち受ける側がないため接続できません。

  設定は終了時に自動保存され、次回起動時に復元されます。
  保存先: %APPDATA%\MALIB\rtknavi_qt.conf / rtknavi_qt.ini
          %APPDATA%\MALIB\rtkplot_qt.ini
